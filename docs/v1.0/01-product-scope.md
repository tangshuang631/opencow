# 01. 产品范围

## 1. v1.0 必须做到

- 基于 `openclaw` 后端能力做中度改造。
- 保留核心功能上限，减少冗余入口、冗余配置和低频复杂路径。
- 默认进入本地 Ollama 工作流。
- 联网搜索、Skills 下载、MCP、RAG、NPC 都作为重要能力保留，并通过权限和开关控制。
- 远程 API 保留在高级设置，不抢占首页。
- 允许 shell，但必须严格受控。
- 关键操作可审计、可中断、可追溯、尽量可回退。
- UI 以白色浅色为主，简洁、美观、迅捷。

## 2. v1.0 不做

- 不做云账号体系。
- 不做多端同步。
- 不做复杂插件市场。
- 不做企业多租户。
- 不做默认全权限自动执行。
- 不做面向浏览器的主体验。
- 不把远程 API 作为首页默认路径。

## 3. 目标用户

- 中国 Windows 用户。
- 本地 Ollama 用户。
- 希望用 AI 处理资料、搜索、总结、文件整理、低代码任务的人。
- 需要高安全、高可靠、可回退本地助手的人。
- 希望 openclaw 能力更轻量、更简单、更适合日常使用的人。

## 4. 成功标准

opencow v1.0 的成功不靠功能堆叠，而靠这些体验成立：

- 新用户打开后能快速看到 Ollama 状态和可用模型。
- 用户不用先理解复杂配置，也能完成基础任务。
- 功能能力不明显低于 openclaw 目标能力，但入口更少、更清楚。
- 高风险操作不会悄悄发生。
- 出错后能看到详细错误、日志和修复建议。
- 常见任务不卡死、不假死、不无声失败。
