# 03. 模型与联网策略

## 1. Ollama 优先

首页只强调 Ollama：

- 检测 Ollama 是否运行。
- 读取本地模型列表。
- 选择聊天模型。
- 选择 Embedding 模型。
- 流式输出。
- 模型不可用时给出诊断和修复建议。
- 普通对话不得把空模型名或 `未选择模型` 占位值发送给 Ollama；App、前端服务层与 Tauri 命令层都必须提前阻断并进入可恢复错误链路。
- 长题目或长文本回答不得直接依赖一次超长输出：
  - 明确声明题型与题数时，按题型分段请求。
  - 没有题型声明但存在连续编号长列表时，按有界编号范围分段请求。
  - 分段回答如果缺少题号，必须自动补问缺失编号并合并结果。
  - 长回答允许更长的前端执行窗口；桌面 Tauri 侧 Ollama HTTP 请求也必须有有界超时，防止后台请求无限悬挂。
  - 用户发送 `继续` 或 `continue` 补写上一轮长度截断回答时，界面仍只展示用户的短指令；用于恢复上下文的内部续写提示只能进入本地模型调用和审计链路，不能在主对话中摊开。

Ollama 的优点必须保留：

- 本地推理。
- 成本低。
- 启动快。
- 切换模型直接。
- 更适合国内网络环境。
- 隐私更可控。

## 2. 远程 API

远程模型保留，但放入高级设置：

- `baseUrl`
- `apiKey`
- `model`
- `provider label`
- 超时
- 重试
- 并发限制

兼容目标：

- OpenAI-compatible API。
- 本地代理。
- `ccswitch` 一类模型切换工具。

默认策略：

- 远程 API 默认关闭。
- 用户可在高级设置手动开启。
- 高级设置至少提供 `baseUrl`、`provider label` 与 `apiKey` 的可编辑入口，v1.0 原型阶段可先不接入完整远程模型选择表单。
- 对话中可以请求开启，但必须由用户确认。

## 3. 联网搜索

联网搜索很重要，但默认关闭。

规则：

- 用户可以在对话中要求开启联网搜索。
- 开启前必须显示将启用的搜索 provider。
- 搜索查询、结果摘要、来源链接必须写入日志。
- 搜索结果注入上下文前必须压缩和限量。
- 搜索结果必须在右侧来源面板可查看。
- 如果联网搜索已开启但当前没有可用外部来源，普通对话必须显式告诉本地模型不要声称已经完成实时联网检索。
- 这种空来源状态必须写入审计细节，例如 `Search context status: enabled-no-sources`，方便用户判断本轮回答是否真的包含外部来源。

## 4. Skills 下载与网络访问

Skills 下载能力保留。

规则：

- 默认关闭自动下载。
- 用户可通过设置或对话请求开启。
- 下载前显示来源、目标目录、风险说明。
- 下载过程必须写入审计日志。
- 下载后需要扫描 manifest 或元数据，不能直接让模型自由执行未知脚本。
