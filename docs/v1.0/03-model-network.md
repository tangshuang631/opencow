# 03. 模型与联网策略

## 1. Ollama 优先

首页只强调 Ollama：

- 检测 Ollama 是否运行。
- 读取本地模型列表。
- 选择聊天模型。
- 选择 Embedding 模型。
- 流式输出。
- 模型不可用时给出诊断和修复建议。

Ollama 的优点必须保留：

- 本地推理。
- 成本低。
- 启动快。
- 切换模型直接。
- 更适合国内网络环境。
- 隐私更可控。

## 2. 远程 API

远程模型保留，但放入高级设置：

- `baseUrl`
- `apiKey`
- `model`
- `provider label`
- 超时
- 重试
- 并发限制

兼容目标：

- OpenAI-compatible API。
- 本地代理。
- `ccswitch` 一类模型切换工具。

默认策略：

- 远程 API 默认关闭。
- 用户可在高级设置手动开启。
- 对话中可以请求开启，但必须由用户确认。

## 3. 联网搜索

联网搜索很重要，但默认关闭。

规则：

- 用户可以在对话中要求开启联网搜索。
- 开启前必须显示将启用的搜索 provider。
- 搜索查询、结果摘要、来源链接必须写入日志。
- 搜索结果注入上下文前必须压缩和限量。
- 搜索结果必须在右侧来源面板可查看。

## 4. Skills 下载与网络访问

Skills 下载能力保留。

规则：

- 默认关闭自动下载。
- 用户可通过设置或对话请求开启。
- 下载前显示来源、目标目录、风险说明。
- 下载过程必须写入审计日志。
- 下载后需要扫描 manifest 或元数据，不能直接让模型自由执行未知脚本。
