# 05. 回退、审计与本地存储

## 1. 本地明文存储

v1.0 默认本地明文存储：

- 会话。
- 附件元数据。
- 日志。
- 快照。
- 知识库索引。
- 权限记录。
- 工具执行记录。

必须提供清理入口：

- 清空会话。
- 清空日志。
- 清空缓存。
- 清空快照。
- 清空知识库索引。

加密存储作为后续增强。

## 2. 对话回退点

对话必须支持可回退点。

规则：

- 默认最多保留 10 段可回退点。
- 高级设置最高可提高到 20 段。
- 用户发出的每条消息旁边提供回退入口。
- 点击后可回退到该消息执行操作之前的状态。
- 回退前显示将回退的范围和影响。
- 回退结果写入审计日志。

回退点应覆盖：

- 会话上下文。
- 工具调用状态。
- 文件改动快照。
- 知识库临时注入状态。
- 任务计划状态。

## 3. 文件快照

文件写入、覆盖、删除、批量修改前应创建快照或副本。

如果无法创建快照：

- 不执行高风险操作。
- 输出原因和建议。
- 允许用户手动确认仅生成方案。

## 4. 审计日志

必须记录：

- 用户消息。
- 模型调用。
- 工具调用。
- shell 命令。
- 搜索查询。
- 搜索来源。
- 文件读取。
- 文件写入。
- 权限变更。
- 弹窗确认。
- 回退操作。
- 错误和堆栈信息。
- 修复尝试。

## 5. 错误可追溯

任何报错都必须能追溯：

- 出错模块。
- 出错时间。
- 输入摘要。
- 工具名称。
- 命令或 API。
- stderr/stdout 或响应体摘要。
- 用户可见错误。
- 可执行修复建议。
