# 09. 分发、更新与开源合规

## 1. 分发策略

v1.0 优先 Windows：

- 开发版启动脚本。
- 本地打包版。
- 安装器后续完善。
- 自动更新后置。

必须降低配置成本：

- 自动检测 Node、Rust、Ollama。
- 缺失依赖时给出中文提示。
- Ollama 未运行时给出启动建议。
- 中文终端脚本强制考虑 `UTF-8`。

## 2. 清理入口

设置页提供：

- 清空会话。
- 清空日志。
- 清空缓存。
- 清空快照。
- 清空知识库索引。
- 重置权限授权。

## 3. 许可证检查

开发前置事项：

- 检查 `openclaw` license。
- 检查 `assistant-ui` license。
- 检查 `cdesktop` license 和可借鉴边界。
- 检查所有新增依赖 license。
- 不把不兼容源码混入主项目。
- 保留第三方声明和许可证文件。

## 4. 引用边界

- `cdesktop` 只作为信息架构参考，除非 license 明确允许并经过确认。
- `assistant-ui` 可作为组件骨架使用，但仍要保留 license 声明。
- `openclaw` 作为后端基础，需要保留上游来源、commit、license 和修改说明。

## 5. 国内用户体验

- 中文优先。
- 文档中文优先。
- 默认本地 Ollama。
- 网络能力可选启用。
- 错误提示可读。
- 安装步骤尽量短。
